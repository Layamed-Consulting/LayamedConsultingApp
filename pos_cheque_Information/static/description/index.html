Blacklist Verification & Cheque Details

Ensure secure transactions with real-time validation

Add to Blacklist

Go to the Point of Sale → Blacklist, and enter the required information such as:

  • Identifiant
  • Client Name
  • Comment
  • Status (OK or KO)

View Blacklist Information

Check that the information has been correctly saved and is visible in the system.

Dangerous Identifiant Alert

When entering a blacklisted Identifiant in the POS session, the system alerts the cashier immediately.

Safe Transaction

If the Identifiant is not blacklisted, the transaction proceeds without any warning.

Check Payment Traceability

After confirming the order, go to the POS backoffice → Orders → Select a transaction → Payments tab → Click the payment line to view full cheque details.
